# Retrospective - Sprint 2

## Wat was het doel?

Het Klantenbeheer Dashboard volledig afmaken.
De klantfuncties bouwen, SEO verbeteren, de website online
publiceren en het project testen.

## Wat ging goed?

- Het dashboard en klantenoverzicht zijn afgerond.
- Alle klantfuncties werken goed.
- Bootstrap is gebruikt voor formulieren, tabellen en modals.
- Klantgegevens worden opgeslagen in localStorage.
- De website is getest met Lighthouse.
- De SEO is verbeterd en vastgelegd in een rapport.
- De website staat online via GitHub Pages.
- Google Search Console is ingesteld.

## Wat ging minder goed?

Sommige onderdelen kostten meer tijd dan verwacht.

## Wat heb ik geleerd?

Meer ervaring opgedaan met Bootstrap en JavaScript.
Ook is duidelijker geworden hoe localStorage werkt
en hoe een website met Lighthouse en Google Search Console
gecontroleerd kan worden.

## Resultaat

Sprint 2 is afgerond.
Alle geplande functies werken en de website is getest
en online gepubliceerd.

Daarmee is het hele project afgerond.
