# Retrospective - Klantenbeheer Dashboard

## Wat was het doel?

Een responsive Klantenbeheer Dashboard bouwen met
HTML, CSS, JavaScript en Bootstrap.

De website moest een loginpagina en een dashboard krijgen
waar klanten beheerd kunnen worden.

## Wat ging goed?

### Sprint 1

- De projectstructuur is opgezet.
- De loginpagina is gebouwd met Bootstrap.
- De navigatie tussen de loginpagina en het dashboard werkt.
- De website is geschikt gemaakt voor verschillende schermformaten.

### Sprint 2

- Het dashboard en klantenoverzicht zijn afgerond.
- Klanten toevoegen, zoeken, bekijken, wijzigen en verwijderen werkt.
- Klantgegevens worden opgeslagen in localStorage.
- De website is getest met Lighthouse.
- SEO is verbeterd en vastgelegd in een rapport.
- De website is gepubliceerd via GitHub Pages.
- Google Search Console is ingesteld.

## Wat ging minder goed?

Sommige onderdelen met Bootstrap kostten meer tijd dan verwacht.

## Wat heb ik geleerd?

Meer ervaring opgedaan met Bootstrap, HTML, CSS en JavaScript.
Ook meer geleerd over Git, GitHub en het werken met branches.

Daarnaast is duidelijker geworden hoe localStorage,
SEO, Lighthouse en Google Search Console werken.

## Eindresultaat

Het Klantenbeheer Dashboard is afgerond in twee sprints.

Alle geplande frontendfuncties werken en de website
is responsive, getest en online gepubliceerd.

Het project voldoet aan de geplande frontenddoelen.
