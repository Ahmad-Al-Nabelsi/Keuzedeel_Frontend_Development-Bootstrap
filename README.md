## Projectbeschrijving

Voor het keuzedeel Frontend Development heb ik een responsive
frontend voor een klantenbeheerapplicatie ontwikkeld met Bootstrap.

De applicatie bestaat uit twee interfaces: een openbare
loginpagina en een Klantenbeheer Dashboard.

Op de loginpagina staan een korte uitleg over de applicatie,
e-mail- en wachtwoordvelden, Inloggen, Wachtwoord vergeten?,
Account aanmaken en een Contact-menu.

Na het klikken op Inloggen gaat de gebruiker naar het dashboard.
Daar kunnen klanten worden toegevoegd, bekeken, gezocht,
gewijzigd en verwijderd.

Bovenaan staat een begroeting met de gebruikersnaam en een
knop Uitloggen. Deze knop brengt de gebruiker terug naar
de loginpagina.

Dit project bevat alleen de frontend. Er is geen echte
authenticatie, backend of database. De klantgegevens worden
lokaal opgeslagen in de browser met localStorage.
